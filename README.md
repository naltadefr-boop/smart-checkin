# Wellness Hôtel – Smart Check-in

Application de réception du Wellness Hôtel Bagjem : scan des pièces d'identité, fiches d’hébergement (PDF, Word, PNG, impression), historique, chambres.

- Fonctionne sans Claude et sans Internet au quotidien (application web installable).
- Mise en ligne gratuite avec GitHub Pages ; base partagée gratuite avec Firebase (fichier `config.js`).
- Voir **GUIDE-INSTALLATION.pdf** pour l'installation pas à pas, et **NOTICE-VERSION-2.pdf** (à lire avant l'étape 2).
